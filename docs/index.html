Vision Statement

The Goal

Transform Ragaban Clinics from a traditional multi-location medical group into a data-driven, AI-assisted healthcare platform that delivers measurable patient outcomes, operational efficiency, and revenue growth — fully compliant with NPHIES, PDPL, and Vision 2030 digital health mandates.

🇸🇦

KSA-Native by Design

Unifonic API

UNIFONIC_API_KEY=your_key_here
NPHIES FHIR
CHI Nphies Portal → Register as Healthcare Provider → Get client_id + secret
NPHIES_CLIENT_ID=your_id_here
Geidea Payment Gateway
geidea.net → Merchant Account → API Keys (mada/Visa/MC)
GEIDEA_API_KEY=your_key_here
STC Cloud
stc.com.sa/cloud → IAM → Create Service Account → Download credentials JSON
STC_CLOUD_CREDENTIALS=/path/to/creds.json
Tawk.to
tawk.to → Property Settings → Get Property ID + Widget Key (FREE)
TAWK_PROPERTY_ID=your_id_here
SDAIA AI Marketplace
sdai.gov.sa → Developer Portal → Request API access for healthcare models
SDAIA_API_KEY=your_key_here

Implementation Roadmap

16-week phased delivery — each phase has defined outputs and success metrics

4 PHASES
Phase 01 Weeks 1-4 — Foundation

Foundation & Data

Deploy STC Cloud infrastructure. Set up OpenMRS EHR across all 4 locations. Integrate Unifonic WhatsApp API for appointment booking. Connect Odoo to OpenMRS.

  • STC Cloud VMs + Kubernetes cluster
  • OpenMRS EHR deployed with Arabic locale
  • Unifonic WhatsApp API live (booking + reminders)
  • Odoo ↔ OpenMRS data sync
  • Deliverable: Working patient booking via WhatsApp
Phase 02 Weeks 5-8 — Intelligence

AI & Automation

Integrate NPHIES FHIR APIs for insurance claims. Deploy AI no-show prediction model. Build Apache Superset analytics dashboard. Add Geidea payment gateway.

  • NPHIES $eligibility + $submit APIs connected
  • AI no-show prediction (SDAIA-certified model)
  • Superset dashboard: patient flow, revenue, no-shows
  • Geidea payment: online appointment deposits
  • Deliverable: 60% faster claim processing
Phase 03 Weeks 9-12 — Experience

Patient Experience Platform

Launch Next.js patient portal (Arabic RTL). Deploy mobile app for iOS/Android. Add AI chatbot for triage. Integrate Tawk.to live chat with agent handoff.

  • Patient portal: bookings, records, payments, chat
  • React Native app (iOS + Android)
  • AI triage chatbot (symptoms → department routing)
  • Tawk.to live chat with Arabic support
  • Deliverable: Unified digital patient experience
Phase 04 Weeks 13-16 — Scale

Advanced AI & Scale

Integrate SDAIA AI Marketplace models for medical imaging. Deploy predictive analytics for inventory and staffing. Add AI-driven marketing automation.

  • AI medical imaging (radiology screening)
  • Predictive inventory for medical supplies
  • AI marketing: patient re-engagement campaigns
  • Full NCA cybersecurity audit
  • Deliverable: AI-first healthcare platform
