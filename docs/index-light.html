Transformation Vision

From traditional multi-location medical group to data-driven, AI-assisted healthcare platform.

Target: 40% reduction in no-show rates via AI-powered reminders. 60% faster insurance claim processing via NPHIES automation. 3x increase in patient satisfaction through unified digital experience.

Every technology choice is born in Saudi context — not translated. NPHIES FHIR integration for insurance claims, SDAIA-certified AI for diagnostics, STC Cloud for data sovereignty, and Unifonic for patient communication.

NPHIES FHIR
CHI Nphies Portal → Register as Healthcare Provider → Get client_id + secret
NPHIES_CLIENT_ID=your_id_here

Geidea Payment Gateway
geidea.net → Merchant Account → API Keys (mada/Visa/MC)
GEIDEA_API_KEY=your_key_here

STC_CLOUD_CREDENTIALS=/path/to/creds.json

SDAIA_API_KEY=your_key_here
